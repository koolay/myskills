# ko-cq-agent-guidelines

约束 coding agent 的日常工作：先理解任务，采用最小可行改动，保护用户工作，并如实报告验证结果。

执行规则以 [SKILL.md](./SKILL.md) 为准；安装方法见[项目 README](../README#安装与使用)。

## 适用场景

实现、调试、审查、重构、解释代码，或希望在整个会话中持续采用统一的 agent 行为准则。

## 使用示例

```text
读取并持续应用 ko-cq-agent-guidelines。修复这个问题前先追踪相关调用，保持改动范围最小，完成后说明实际验证结果。
```

## 输入与产出

- **输入：** 任务、仓库指令、相关文件、错误、已有检查、授权范围和此前决策。
- **产出：** 具体结果、已完成与未完成状态、执行过的检查、限制；需要用户操作时给出一个可立即开始的动作。

## 执行流程

1. 先检查上下文，明确范围、重要假设和可观察的成功条件。
2. 复用已有能力，采用满足要求的最小实现。
3. 只改与任务有关的内容，保留无关用户改动。
4. 逐项验证成功条件，区分通过、失败、阻塞和未执行。

## 边界与前提

激活后跨后续话题持续生效，但始终服从工具的指令层级和用户明确变更。重大歧义、未授权破坏操作、访问阻塞需要暂停相关工作。连续三轮同一问题仍未解决时停止猜测，提出一个诊断问题。
