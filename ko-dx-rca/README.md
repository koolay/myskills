# ko-dx-rca

从症状追踪到证据支持的因果链，搜索同类路径，并区分局部修复与能防止同类问题的修复。

执行规则以 [SKILL.md](./SKILL.md) 为准；安装方法见[项目 README](../README#安装与使用)。

## 适用场景

报告 bug、询问行为原因、要求 5-Why 分析，或验证已有修复是否真正处理了根因。

## 使用示例

```text
使用 ko-dx-rca 分析为什么保存后页面显示旧数据。入口在 src/editor，重点检查保存、重试和历史回放路径，并判断现有补丁是否只修了一个场景。
```

## 输入与产出

- **输入：** 症状或待检查补丁；可选的复现步骤、错误、相关文件、近期变更和前后端或基础设施范围。
- **产出：** RCA 报告：症状、带源码位置的 Why 链、Point / Class / Hybrid 修复分类、同类路径、证据闭环和剩余风险。

## 执行流程

1. 定位每个独立症状及其数据流。
2. 逐层读取源码回答 Why，直到发现可解释问题的根因，不强凑五层。
3. 提炼失败模式与应守住的不变量，搜索同类调用并区分确认、可能与不适用。
4. 给出具体修复建议，正向复核因果链、替代解释和覆盖缺口。

## 边界与前提

每个因果判断都要有源码证据，推测需标注。找不到相关代码或症状无法定位时先补充上下文。分析请求提供报告和修复建议；实施修复仍需对应授权。
