# ko-ux-agent-design

设计 AI Agent 与用户的持续协作体验，覆盖跨会话任务、可控记忆、授权行动、共同规划和错误恢复。

执行规则见 [SKILL.md](./SKILL.md)；安装方式见[项目 README](../README#安装与使用)。

## 使用示例

```text
使用 ko-ux-agent-design，设计团队项目助手。用户每周回来推进同一项目，需要恢复进度、纠正旧偏好、删除个人记忆。助手可以准备邮件草稿，发送需要用户授权。只出交互方案，不写代码。
```

## 输入与产出

- **输入：** 用户目标、使用周期、现有流程、记忆和工具能力、数据与授权边界。
- **产出：** 记忆契约、动作授权表、连续协作流程、失败恢复、验收场景和效果指标。
- **边界：** 不处理一般视觉润色或单纯框架选型；默认只设计，不持久化用户信息或执行外部动作。

## 来源与本地适配

学习 [bencium 的 Relationship Design](https://github.com/bencium/bencium-marketplace/blob/main/relationship-design/skills/relationship-design/SKILL.md)，独立编写本技能；强调显式权限、最小记忆、数据隔离、可核实的恢复能力和验收。没有复制上游附属文件。

## 验证记录

2026-09-30 对 [evals/evals.json](./evals/evals.json) 中三个场景进行了作者人工规则走查。基线是预期失败，不是独立 Agent 实测；结果是设计推演，不是产品运行测试。

| 场景 | 无技能的可能失败 | 应用规则后的设计结果 |
| --- | --- | --- |
| 项目助手返回、偏好更改和发送邮件 | 沿用旧偏好；以历史成功为由自动发送 | 当前偏好替换旧偏好；恢复未完成计划；生成可审阅草稿，未授权发送保持待授权 |
| 删除个人记忆，检索索引无法即时清除 | 宣称全部忘记；团队仍能检索个人记录 | 分离个人和团队范围；立即停止读取，清除状态显示待处理，明确派生索引和备份限制，不承诺即时彻底删除 |
| 静态活动页换标题颜色 | 引入长期记忆、信任分级和完整工作台 | 不触发关系设计流程，按普通 UI 任务处理 |
