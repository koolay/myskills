# ko-ux-innovative-design

从主题自身的语言与行为建立独立视觉语言；用户看过并锁定方向后，再制作实际作品。

执行规则以 [SKILL.md](./SKILL.md) 为准；安装方法见[项目 README](../README#安装与使用)。

## 适用场景

原创品牌、活动、出版物或网站需要差异化方向，或需要继续此前已锁定的设计。

## 使用示例

```text
使用 ko-ux-innovative-design，为社区修理活动探索原创视觉方向。目标是让居民感到旧物值得修复，主题文案保持“修好，再用。”。先让我看方向，暂不制作正式物料。
```

## 输入与产出

- **输入：** 主题与意图、精确文案及已有证据；可选已选或锁定方向、交付范围、技术栈和素材权利。
- **产出：** 第一轮：A-J.html、中性 index.html 和首次视觉反馈前不展示的概念记录。明确锁定后：ROUND-2-CONTEXT.md、约定作品；用户接受后：STYLEGUIDE.html。

## 执行流程

1. 恢复已有状态；主题与意图充分时直接从最小证据开始。
2. 隔离当代设计参考，将真实机制转化为形式，按需求核实字体与许可。
3. 独立创作十个只含文字、平面颜色和留白的 HTML 方向，检查源码。
4. 让用户进行首次视觉判断，区分喜欢、选择和明确锁定。
5. 锁定后制作精确范围的作品并验证，用户接受后冻结规则与风格指南。

## 边界与前提

第一轮 agent 不打开、渲染或截图评判；不浏览画廊、模板或 Google Fonts 寻找风格。所有阶段禁止生成 SVG。许可、可访问性与恢复能力是固定边界；普通 UI 修复和应用已有设计系统不走十方向探索。
